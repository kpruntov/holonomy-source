# Security Policy

## Supported Versions

Currently, only the latest version of Holonomy is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < v0.1.0| :x:                |

## Reporting a Vulnerability

We take the security of Holonomy very seriously. If you believe you have found a security vulnerability in the Holonomy source-available project (including the Rust core and Python distribution wrapper), please report it to us as described below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them to us via email:

*   **Email:** security@holonomy.io

### What to include in your report

Please include the following information in your report to help us understand and resolve the issue quickly:

*   **Description of the vulnerability:** What is the issue, and what is its potential impact?
*   **Steps to reproduce:** How can we reproduce the vulnerability? Please provide as much detail as possible, including code snippets or proof-of-concept (PoC) scripts if you have them.
*   **Affected versions:** Which versions of Holonomy are affected? (e.g., v0.1.2)
*   **Environment details:** What operating system, Python version, and Rust version were you using?

### What to expect

1.  **Acknowledgment:** We will acknowledge receipt of your vulnerability report within 48 hours.
2.  **Triage:** We will triage the report and determine if it is a valid security issue.
3.  **Remediation:** If the vulnerability is valid, we will work on a fix and release a patch as quickly as possible.
4.  **Disclosure:** Once the fix is released, we will publicly disclose the vulnerability (with your permission and credit) to ensure that users can update their systems.

Thank you for helping us keep Holonomy secure!
